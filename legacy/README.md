# Historical code

These are unmodified copies made before the October 27, 2026 repair. They are
retained for comparison with the supplied checkpoints, not as supported training
entry points. They mix incompatible interfaces and omit trained encoder modules.
Do not add this directory to PYTHONPATH or launch these scripts for a new run.

Use the root README and the versioned models in `diffusion/`. Original data and
large checkpoints have not been changed or removed. Legacy checkpoints are
explicitly rejected by the new loader; the new stages must be trained.
